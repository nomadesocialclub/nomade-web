nomade favicon pack

Incluye:
- favicon.ico: archivo principal para web, con 16/32/48/64/128/256 px embebidos.
- favicon.svg: versión vectorial editable.
- favicon-512x512.png: versión alta calidad.
- apple-touch-icon.png: icono para iOS.
- android-chrome-192x192.png y android-chrome-512x512.png: iconos PWA/Android.
- site.webmanifest: manifest básico.

Recomendación:
Enviar el ZIP completo. Para implementación web, normalmente basta con favicon.ico, favicon.svg, apple-touch-icon.png, android-chrome-192x192.png, android-chrome-512x512.png y site.webmanifest.
